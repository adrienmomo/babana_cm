# Écart L0-10 — FCM_* n'a pas besoin d'exception

`amoa/specs/L0-socle.md` (L0-10, rédigée le 13 septembre) donne comme exemple d'exception
attendue, aux côtés de `SMS_GATEWAY_*` : « `FCM_*` sans fournisseur ». Vérifié dans le dépôt avant
de recopier cette phrase dans `tools/config-coherence/variables.ts` (CLAUDE.md : une dépendance
supposée absente se vérifie dans le dépôt, jamais dans le prompt) — elle est fausse aujourd'hui.

`FCM_PROJECT_ID`, `FCM_CLIENT_EMAIL` et `FCM_PRIVATE_KEY` sont :

1. **déclarées** dans `infra/env/.env.example` (vides, D19 : `PUSH_PROVIDER=console` par défaut,
   aucun compte Firebase requis) ;
2. **livrées** à Odoo par `infra/compose.yaml` (`FCM_PROJECT_ID: ${FCM_PROJECT_ID:-}` et les deux
   autres) ;
3. **consommées** par `services/odoo/addons/babana/services/push.py` —
   `FcmPushProvider.from_env()` les lit (via la convention locale `FCM_PROJECT_ID_ENV =
   "FCM_PROJECT_ID"`), construit l'assertion JWT, et appelle l'API HTTP v1 de Firebase Cloud
   Messaging. Le code existe déjà en entier, avec ses tests (`tests/test_push.py`).

Les trois moments tiennent : ce n'est pas un maillon manquant au sens de L0-10, donc pas une
exception. Ce qui manque réellement n'est pas de la configuration mais de la **vérification** —
personne n'a encore exercé `FcmPushProvider` contre un vrai compte Firebase (aucun compte externe
cette nuit, D19) — et ce n'est pas ce que le protocole des trois moments mesure.

**Cause probable** : la spécification a été écrite en généralisant depuis `SMS_GATEWAY_*` (qui,
lui, est un vrai maillon manquant — L1-09 n'existe pas) sans revérifier l'état de L7-01, déjà fait
depuis.

**Conséquence** : `tools/config-coherence/variables.ts` ne liste PAS `FCM_*` dans `EXCEPTIONS`.
Le test `test/config/config-coherence.test.ts` le confirme mécaniquement — s'il fallait une
exception, la suite échouerait dès qu'on la retire (`FCM_PROJECT_ID : déclarée et livrée mais
aucune consommation détectée`, ce qui ne se produit pas).

Aucune décision d'architecture à arbitrer ici — juste une phrase de spécification à ne pas
recopier telle quelle. `docs/operations/configuration.md` porte la correction pour la prochaine
lecture.
